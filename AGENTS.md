# GameHungerG — инструкции для агентов

## Команды

- Запуск: открыть `index.html` в браузере. Сборка и сервер не нужны.
- Проверка: `node scripts/check-game.cjs`.
- Ручной сценарий: меню → старт → сбор → кормление → пауза → рестарт → game over.

## Конвенции

- Vanilla HTML/CSS/JavaScript, без зависимостей, CDN и сетевых запросов.
- Вся игра находится в `index.html`; `scripts/` содержит только проверки.
- Canvas 2D, логическое поле 1280×720, фиксированный шаг симуляции 1/60.
- Звук создаётся процедурно через WebAudio и включается после действия пользователя.
- Локальное хранилище используется только для рекорда и настройки звука.
- Заголовки и интерфейс — обычный регистр.

## Структура

- `index.html` — разметка, стили, игровой цикл, рендер, ввод и звук.
- `scripts/check-game.cjs` — синтаксическая и логическая проверка без фреймворков.
- `docs/CONTEXT.md` — состояние, глоссарий и журнал.
- `docs/DECISIONS.md` — архитектурные решения.
